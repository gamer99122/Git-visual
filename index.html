Git 指令動畫

依 Will 保哥（黃保翕）《30 天精通 Git 版本控管》整理。點一個指令看它做了什麼。

每段動畫都是獨立範例。C1、C2 是示意用的 commit 編號，實際操作請用 git log --oneline 查到的 ID。範例使用 master，請以你的分支名稱為準。

U 未追蹤M 已修改 A 新增D 刪除R 改名 ■ 本地分支■ 遠端追蹤分支■ 標籤■ HEAD（目前位置）虛線 commit = 從圖中的分支或標籤已無法沿歷史到達

卡片只顯示範例相關的檔案或變更。git add 將當下的內容存入索引，原檔仍留在工作目錄。git commit 將索引的完整快照存成一個版本。
