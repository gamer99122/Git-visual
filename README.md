# Git 指令動畫

用動畫學 Git：點一個指令，就能看到它對工作目錄、暫存區、本地與遠端儲存庫做了什麼。

**👉 線上網站：<https://gamer99122.github.io/Git-visual/>**

## 特色

- 收錄 40 個 Git 指令，分成：建立與設定、日常操作、分支、修正歷史、遠端協作、底層與工具
- 每個指令都有逐步動畫：檔案在工作目錄 / 暫存區 / Stash 之間移動，commit、分支、HEAD、標籤的變化一目了然
- 每一步附上終端機指令與輸出、中文說明，以及「常用寫法」表
- 可用 ← → 逐步觀看、空白鍵播放 / 暫停
- 網址可直接指定指令，例如 [`#rebase`](https://gamer99122.github.io/Git-visual/#rebase)、[`#merge`](https://gamer99122.github.io/Git-visual/#merge)
- 支援手機版面與深色模式

## 本機使用

整個網站只有一個 `index.html`，沒有任何外部相依，下載後用瀏覽器直接開啟即可。

## 參考教材

內容依 Will 保哥（黃保翕）的《[30 天精通 Git 版本控管](https://github.com/doggy8088/Learn-Git-in-30-days)》整理，每個指令都附有對應章節的連結，建議搭配原文一起閱讀。
